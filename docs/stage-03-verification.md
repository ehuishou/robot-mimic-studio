# 第三阶段验证记录：双上臂动作映射

实施与验证跨越 2026-10-23 / 2026-10-24（Asia/Shanghai）。版本：0.3.0；上一阶段基线：`40be800c3b7b054d1ea17a48d9567b23ddb19984`。

## 交付范围

- 新增 `mapping.html`：同页三维机器人、模拟姿态与本机摄像头输入；模型工作台和姿态识别页均提供入口。
- 默认模拟输入，不自动请求摄像头。支持左右独立、双臂外展、前伸、向上限位、低置信度、缺失和无效坐标。
- 上臂驱动采用父空间方向求解、实际静止姿态、固定扭转约定、160° 最大摆角、四元数 SLERP；输入丢失先保持 250ms，再回中。
- 近反向输入复用连续摆动参考轴，避免将微小噪声放大成任意轴翻转。重置精确恢复保存的位置/旋转/缩放，并暂停跟随。
- 采集代码提取为 `src/mobile/capturePanel.ts`，两个页面共用第二阶段的后摄、具体镜头选择、原生变焦、取消授权与资源清理逻辑。
- 映射观察显示世界坐标及置信度、方向、实际绑定路径、目标/当前四元数、角差、状态及限位提示。骨架面板列出实际名称、父节点和初始四元数。
- 新增可选 `models/robot.mapping.json`：显式路径、实际名称、轴修正及限位配置；未知 GLB 不自动猜名字。缺少配置、路径错误或不支持变换时告警并停用对应链。

## 坐标与算法约定

- 从 MediaPipe `worldLandmarks` 构造 `{timestampMs, seq, coordinateSpace, worldLandmarks}`。图像归一化坐标继续只用于叠加绘制，不作为世界坐标替代。
- 世界坐标按米和髋部中心语义处理；使用相对方向，不迁移人体根位置。显示转换为 `(x,-y,-z)`，对应场景 +Y 向上、+Z 朝正面观察者；机器人解剖左侧位于 +X。
- 本版为相机相对方向跟随，尚未加入人体躯干标定或肩部完整坐标架恢复。模拟方向和桌面真实模型联通已验证；真实人物的左右、前伸、侧身及前后摄一致性仍需真机确认。
- 自拍镜像只用于视频与叠加显示，不交换原始点或机器人左右。父节点当前世界旋转、模型根旋转和保存的静止旋转参与目标计算。
- 基于最小 swing 对齐方向，轴向 twist 固定；这不是完整动作捕捉。摆角限位是保守的锥形限制，不表示解剖准确的肩关节限制，也不保证没有模型自穿插。
- 当前支持正的均匀缩放和直接相连的肩肘骨骼链。负缩放、非均匀缩放、剪切及中间辅助骨骼需要独立适配。
- 序号/时间戳验证拒绝重复、乱序、非有限、过期和明显超前帧。每侧单独验证端点置信度与方向长度；渲染不会刷新观察时间。

## 自动化验证

本地环境：Windows、Node.js 24.22.1、Edge 无头浏览器。下列结果基于生产构建，摄像头为 Canvas 模拟流。

- `npm run typecheck`：通过。
- `npm test`：21/21 通过。包含左右独立、旋转父节点与非零 rest、短暂保持/回中、无效及零长度输入、陈旧/乱序/重复帧、反向方向及连续性、30/60/120Hz 平滑一致性、暂停/精确复位/dispose、配置校验和不支持变换。
- `npm run build`：通过。三个 HTML 入口、同源 MediaPipe 资源完整。Three.js 渲染共享包仍有构建体积提示；不影响构建通过。
- `npm run test:browser`：原模型展示与调试回归通过，包含真实 skin/joints 结构的合成 GLB、无骨骼 GLB、无效模型和 WebGL 上下文丢失。
- `npm run test:pose`：原姿态页回归通过，包含授权/模型/WASM 失败、延迟取消、切镜头竞态、串行变焦、不支持变焦、应用失败、停止/重启、退出和 390/320px。
- `npm run test:retarget`：模拟左右独立、暂停/重置、异常恢复、390/320px、集成后摄/变焦/切前摄、切源与退出清理、单一模型加载检查；合成 GLB 的实际名称/显式 JSON 配置驱动与复位，以及缺配置、路径不匹配告警均通过。
- 开启 `POSE_PERSON=1`：真实 MediaPipe/WASM 对官方人体测试图的模拟视频输出 33 点，并实际驱动上臂；不是模拟推理返回值。

具体截图与运行输出保存在不入库的 `artifacts/`。在线部署版本通过 `/version.json` 与 GitHub 提交对应。

## 桌面五分钟连续采样

已执行 `POSE_PERSON=1 MAPPING_DURATION=300`，使用官方人体测试图的 Canvas 模拟视频和真实 MediaPipe/WASM，同页持续驱动机器人。共 30 个间隔约 10 秒的采样：

- 每个采样返回 33 个关键点，仅一条活动采集流，所有上臂四元数均为有限值。
- 推理采样 10.8–15.7 FPS，渲染采样 70–99 FPS；渲染帧率与人体推理帧率分开记录。
- 可观测 JS heap 约 23.9–31.5 MB，末次约 26.2 MB；期间有垃圾回收波动，没有持续单调增长。该指标不是总进程/GPU/WASM 内存，也不能证明不存在泄漏。
- 结束后切前摄、停止/切源及 pagehide 清理检查通过，无额外外部请求，无页面异常。
- 完整原始采样保存为 `artifacts/retarget-sustained-300s.json`（不入库）。这仍是桌面自动化数据，真机连续运行保持待验收。

五分钟采样后仅调整了方向箭头的遮挡显示和未绑定状态提示；最终构建另行执行功能复查，不重复将桌面采样表述为真机结果。
